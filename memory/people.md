# people/INDEX.md

One page per person: `people/<slug>.md`. Closest relationships first.

## Template (`people/<slug>.md`)

```markdown
# Jane Doe

- **Relationship:** friend / colleague / family / vendor
- **Context:** how the user knows them, shared history
- **Facts:** durable details (timezone, contact prefs, kids, ...)
- **Open threads:** anything pending involving them
```

## Rules

- One page per person; merge duplicates by slug.
- Only what the user shared or what's needed for tasks — no dossiers.
- INDEX.md lists everyone, closest first, one line each.
