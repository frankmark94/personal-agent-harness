# groups/INDEX.md

One page per group/community: `groups/<slug>.md`.

## Template (`groups/<slug>.md`)

```markdown
# Running club

- **What it is:** weekly 5k group, meets Saturdays
- **User's role:** regular member
- **People:** links to people/<slug>.md pages
- **Open threads:** upcoming events, things to follow up on
```

## Rules

- Groups get pages when the user has ongoing involvement, not for
  one-off mentions.
- INDEX.md lists every group, most relevant first.
